# 🧠 English Trainer — Java

Projeto desenvolvido em Java para treinar vocabulário em inglês diretamente pelo terminal, utilizando fundamentos importantes da programação, como arrays, métodos, estruturas de repetição, condicionais e menu interativo.

---

## 🚀 Funcionalidades

- 🔤 Expansão de vocabulário por categorias
- 🐾 Categoria de animais
- 🎒 Categoria de objetos
- 🧠 Quiz interativo de inglês
- 📊 Sistema de pontuação
- 🔁 Menus com repetição
- 🧩 Código organizado em métodos
- 💻 Execução totalmente pelo terminal

---

## 🛠️ Tecnologias e conceitos utilizados

- Java
- Scanner
- Arrays
- Métodos
- Estrutura de repetição `while`
- Estrutura de decisão `switch`
- Condicionais `if/else`
- Manipulação básica de entrada de dados

---

## 📌 Como funciona

Ao iniciar o programa, o usuário acessa o menu principal:

```text
=== ENGLISH TRAINER ===
| 1 - EXPANDIR VOCABULARIO |
| 2 - Quiz                 |
| 0 - Sair                 |
===========================
Escolha:
```

Na opção de vocabulário, o usuário pode escolher entre categorias:

```text
== MENU ==
1 - nome de animais
2 - nome de objetos
0 - encerrar
escolha:
```

---

## 🔤 Expansão de vocabulário

O sistema exibe palavras em português junto com sua tradução em inglês.

### Exemplos de animais

```text
leão = lion
cachorro = dog
pato = duck
cavalo = horse
gato = cat
```

### Exemplos de objetos

```text
calculadora = calculator
carregador = charger
ventilador = fan
cortina = curtain
garrafa = bottle
```

---

## 🧠 Quiz

O quiz apresenta perguntas de múltipla escolha, informa se a resposta está correta ou errada e mostra a pontuação final.

Exemplo:

```text
Qual a tradução de 'house'?
1 - Casa
2 - Comida
3 - Camisa
```

Ao final:

```text
Seus pontos: 3/3
```

## 📦 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/jviclima2005-boop/english_trainer.git
```

### 2. Acesse a pasta do projeto

```bash
cd english_trainer
```

### 3. Compile o arquivo Java

```bash
javac English.java
```

### 4. Execute o programa

```bash
java English
```

## 🎯 Objetivo do projeto

Este projeto foi criado com o objetivo de praticar lógica de programação em Java de forma aplicada, unindo aprendizado de inglês com conceitos fundamentais da linguagem.

Durante o desenvolvimento, foram praticados:

- Criação de menus interativos
- Organização do código em métodos
- Uso de arrays para armazenar dados
- Controle de fluxo com `switch` e `if`
- Repetição com `while`
- Entrada de dados com `Scanner`
